This month I started contributing to [peer-observer](https://github.com/peer-observer/peer-observer), a tool that watches what a Bitcoin node sees on the P2P network.

- Set up a VM with a Bitcoin Core node and spent time understanding how the project is put together.
- Opened [#301](https://github.com/peer-observer/peer-observer/issues/301) to improve the setup docs, after a first chat with the maintainer.
- Got my first PRs merged: [#302](https://github.com/peer-observer/peer-observer/pull/302) and [#309](https://github.com/peer-observer/peer-observer/pull/309), which add four new RPCs to the RPC extractor, with tests and Prometheus metrics.
