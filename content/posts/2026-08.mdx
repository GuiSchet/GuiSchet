The July pilot turned into a real project.

- Built [bip300-monitor](https://github.com/GuiSchet/bip300-monitor): an eCash node, the enforcer, NATS and an event extractor, all reproducible and with automated checks.
- Deployed it on a dedicated VM on the Drynet3 test network. The node is synced and the rest waits for historical validation to finish.
- Finished the requested changes on peer-observer [#459](https://github.com/peer-observer/peer-observer/pull/459).
- Prepared a [LABITCONF](https://www.labitconf.com/) workshop proposal about observing Bitcoin from your own node.
